## Bug Fixes

- The `ztunnel` image reference is now included in the regular (non-experimental) release manifest. Previously, it was incorrectly stripped by a kustomize overlay. The `config/regular` overlay has been removed; the regular manifest is now built directly from `config/default`, aligning both channels. See [PR #2308](https://github.com/kyma-project/istio/pull/2308).
