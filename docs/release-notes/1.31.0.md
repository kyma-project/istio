## Istio Updated to Version 1.30.4

We've updated the Istio version to 1.30.4. See [Announcing Istio 1.30.4](https://istio.io/latest/news/releases/1.30.x/announcing-1.30.4/).

## Enhancements

- The Istio module now installs and manages the standard [Kubernetes Gateway API](https://gateway-api.sigs.k8s.io/) CRDs. The `gateways.gateway.networking.k8s.io` CRD carries `kyma-project.io/managed-gateway-api: "true"` label without which the CRDs are not managed. See [Gateway API CRDs Management](../user/00-55-gateway-api-crds.md) and [PR #2242](https://github.com/kyma-project/istio/pull/2242).
- The `Processing` state is now only set when the Istio CR is first installed or when the spec changes. Previously, the module switched to `Processing` on every reconciliation, making it harder to observe steady-state readiness. See the [Module Status Handling](https://github.com/kyma-project/istio/blob/main/docs/contributor/adr/0010-module-status.md) architecture decision record.
- Now, you can configure dual-stack support (IPv4 and IPv6) for the Istio service mesh using the `istio-features` ConfigMap in the `kyma-system` namespace. This is a beta feature. See [PR #2213](https://github.com/kyma-project/istio/pull/2213).
