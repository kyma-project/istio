# Troubleshooting

The troubleshooting section aims to identify the most common recurring problems the users face when they use the Istio module, as well as the most suitable solutions to these problems. See also [Troubleshooting Istio](https://github.com/istio/istio/wiki/Troubleshooting-Istio).

## Guides

- [Prerequisites and Architecture](./03-00-prerequisites.md) - Install the required tools and learn how a request flows through the service mesh. Start here before running network diagnostics.
- [Network Connectivity - Diagnostics](./03-01-network-connectivity.md) - Step-by-step diagnostics for external connectivity issues, covering the ingress gateway, Gateway resource, DNS, external firewalls, and Istio traffic resources.
- [Increase Verbosity of the Istio Ingress Logs](./03-05-increase-verbosity-of-ingress-logs.md) - Enable Istio access logs to see whether requests reach the Ingress Gateway and what happens to them.
- [Diagnosing 503 Errors](./03-10-503-diagnostics.md) - Determine whether a `503 Service Unavailable` response comes from the service mesh having no healthy upstream or from your application, and fix the right component.
- [Diagnosing 403 Errors](./03-11-403-diagnostics.md) - Determine whether a `403 Forbidden` response comes from an Istio AuthorizationPolicy, your application, or an external firewall, and fix the right component, including the port-in-Host-header case.
- [Diagnosing 404 Errors](./03-12-404-diagnostics.md) - Determine whether a `404 Not Found` response comes from incomplete routing, a Gateway host conflict, or your application, and fix the right component.
- [Connection Refused Errors](./03-20-connection-refused.md) - Fix `Connection reset by peer`, `GOAWAY`, `Connection refused`, or connection timeout errors caused by mTLS between sidecar and non-sidecar services or by a NetworkPolicy that blocks the traffic.
- [Istio Sidecar Proxy Injection Issues](./03-30-istio-no-sidecar.md) - Find out why Pods don't get an Istio sidecar proxy injected and how to enable injection.
- [Incompatible Istio Sidecar Version After the Istio Module's Update](./03-40-incompatible-istio-sidecar-version.md) - Manually restart workloads whose sidecar version no longer matches the installed Istio version after an update.
- [Pods Created by Jobs Can't Finish](./03-45-jobs-cant-finish.md) - Resolve Job Pods stuck in `NotReady` because a regular `istio-proxy` container keeps running after the main container exits.
- [Init Containers Can't Access the Network](./03-46-init-containers-cant-access-network.md) - Restore network access for init containers blocked by a regular `istio-proxy` sidecar.
- [Istio Module Deletion Blocked](./03-50-recovering-from-unintentional-istio-removal.md) - Unblock Istio module deletion when Istio or Gateway API resources still exist in the cluster.
- [Changes to Istio Resources Are Not Reverted After Reconciliation](./03-70-reconciliation-fails-on-istio-install.md) - Recover from failed reconciliation when an injected container prevents Istio Deployments from starting.
- [SAP HANA Database Connection Issues](./03-80-cannot-connect-to-hana-db.md) - Troubleshoot failures connecting an application to an SAP HANA Database instance.
- [Istio Cannot Verify an HTTPS Certificate Generated by a Trusted Signing CA](./03-90-istio-cert-unknown.md) - Fix `x509: certificate signed by unknown authority` errors when Istio does not trust the server's root CA.
- [Uneven Traffic Distribution with DestinationRules](./03-95-uneven-load-balancing-with-destination-rules.md) - Understand skewed load distribution caused by locality load balancing that outlier detection implicitly enables.

If you can't find a solution, check for open issues in the [Istio GitHub repository](https://github.com/kyma-project/istio/issues). If none of them addresses your problem, create a new one. You can also reach out to our [Slack channel](https://kyma-community.slack.com/) to get direct support from the community. <!-- markdown-link-check-disable-line -->
