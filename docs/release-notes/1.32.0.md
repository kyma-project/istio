
## Enhancements

- Now, you can enable ambient mode for the Istio service mesh using the `istio-features` ConfigMap in the `kyma-system` namespace. This is a beta feature. See [Beta Istio Features](https://kyma-project.io/external-content/istio/docs/user/beta-features/README.html) and [PR #2274](https://github.com/kyma-project/istio/pull/2274).
