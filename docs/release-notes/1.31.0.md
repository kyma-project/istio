
## Enhancements

- The `Processing` state is now only set when the Istio CR is first installed or when the spec changes. Previously, the module switched to `Processing` on every reconciliation, making it harder to observe steady-state readiness. See [ADR-0010](../contributor/adr/0010-module-status.md).
- Now, you can configure dual-stack support (IPv4 and IPv6) for the Istio service mesh using the `istio-features` ConfigMap in the `kyma-system` namespace. See [#2213](https://github.com/kyma-project/istio/pull/2213).

## Istio Updated to Version 1.30.4

We've updated the Istio version to 1.30.4. See [Announcing Istio 1.30.4](https://istio.io/latest/news/releases/1.30.x/announcing-1.30.4/).
